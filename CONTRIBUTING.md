# 🤝 Contributing to GitHub Activity Generator

Thank you for your interest in contributing to **GitHub Activity Generator**! Open source thrives because of people like you.

---

## 🌟 How Can You Contribute?

- **Submit Quotes**: Add inspiring, witty, or profound tech & programming quotes to `config.json` or `activity_generator.py`.
- **Report Bugs**: If something isn't working as expected, open an issue using the Bug Report template.
- **Suggest Features**: Have ideas for new CLI flags, visual stats, or scheduler options? We'd love to hear them!
- **Improve Documentation**: Found a typo or want to make the README even clearer? PRs are welcome.

---

## 🛠️ Development Workflow

1. **Fork the repository** on GitHub.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/<YOUR_USERNAME>/github-activity-generator.git
   cd github-activity-generator
   ```
3. **Create a new branch**:
   ```bash
   git checkout -b feature/my-cool-feature
   ```
4. **Make your changes** and test them locally:
   ```bash
   python activity_generator.py --dry-run
   python activity_generator.py --stats
   ```
5. **Commit your changes**:
   ```bash
   git commit -m "feat: add support for custom quote themes"
   ```
6. **Push to your fork and submit a Pull Request**!

---

## 📜 Code Style & Philosophy

- Keep dependencies at **zero external packages** whenever possible (standard library only).
- Keep commit histories clean and safe.
- Respect community guidelines outlined in our [Code of Conduct](CODE_OF_CONDUCT.md).
