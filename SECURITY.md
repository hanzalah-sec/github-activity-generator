# 🛡️ Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security issue in **GitHub Activity Generator**, please notify the maintainers privately rather than opening a public issue.

- Create a private security advisory through the GitHub repository's **Security** tab.
- We will respond promptly and provide a fix or guidance.
